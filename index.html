Arabic Sentiment Analysis with AraBERT

PyTorch, Hugging Face Transformers, AraBERT, Python
[GitHub Repository]

Standard language model tokenizers struggle with Arabic because prefixes, conjunctions, and clitics attach directly to root words, fragmenting semantic representations. This project implements an end-to-end Arabic sentiment classification pipeline built around AraBERT, combining Arabic morphological preprocessing with transformer fine-tuning in PyTorch and Hugging Face.
